পুশ নোটিফিকেশন গাইড

এক JSON ফাইলেই পুরো মেসেজ

নোটিফিকেশন বারে দেখায় Firebase-এর title, text আর image। অ্যাপের ভিতরের পেজ বা কুইজ আসে GitHub-এ রাখা JSON ফাইল থেকে, অ্যাপে যে ভাষা বাছা সেই ভাষায়।

নোটিফিকেশন বারFirebase-এর title, text, image
অ্যাপের ভিতরেjson_url-এর JSON থেকে সব কিছু
ক্যাশpush আসলেই নেমে থাকে, পরে নেট ছাড়াও খোলে
📤 পাঠানোFirebaseধরনNotification ReminderFeedbackQuizনিয়ম

📤 কীভাবে পাঠাবেন

দুই উপায়ে পাঠানো যায়। Admin পেজ সহজ: JSON ফাইল বানাতে বা GitHub-এ দিতে হয় না।

🖥️
Admin পেজসহজ · সুপারিশকৃত
  1. পেজ খুলে admin পাসওয়ার্ড দিন। “মনে রাখো” দিলে পরে আর চাইবে না।
  2. উপরের ট্যাবে ধরন বাছুন: Notification · Reminder · Feedback (WhatsApp / Email) · Quiz। এটাই type, আলাদা লিখতে হয় না।
  3. ✍️ ঘর পূরণ করে: সব ঘর পূরণ করুন, JSON নিজে থেকেই বানায়। অথবা 🔗 নিজের JSON লিংক: GitHub-এর ফাইলের লিংক দিন, পাঠানোর আগে যাচাই হয়।
  4. নোটিফিকেশন বারের ঘর খালি রাখলে পেজের শিরোনাম আর লেখা থেকে নেয়।
  5. দরকার হলে full_screen আর return_on_close-এ টিক দিন।
  6. আগে ডিবাগ ফোনে (টেস্ট) পাঠান — শুধু flutter run করা ফোনে যায়। ঠিক থাকলে সব ইউজারকে।
Admin পেজ খুলুন →
🔥
Firebase Consoleনিজে সব ঘর দিয়ে
  1. JSON ফাইল বানিয়ে GitHub-এ দিন (নিচের ধরন অনুযায়ী)।
  2. Firebase Console → Messaging → New campaign → Notifications।
  3. Notification title, text, image দিন।
  4. Target-এ Topic all (সবাই) বা অ্যাপ বাছুন।
  5. Custom data: json_url, type, দরকারে full_screen আর return_on_close।
  6. “Send test message”-এ নিজের ফোনের FCM token দিয়ে আগে দেখুন।
